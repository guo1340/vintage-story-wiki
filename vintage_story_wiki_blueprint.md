# Vintage Story Wiki — Complete Project Blueprint

## Project Goal

Build a high-quality searchable wiki website for the survival sandbox game Vintage Story that follows the same clean, practical, information-dense philosophy as the Project Zomboid wiki project.

The site should feel:

- Rustic
- Immersive
- Practical
- Survival-focused
- Handmade / medieval
- Knowledge-heavy
- Community-driven

The goal is NOT to make a fandom-style cluttered wiki.
The goal is to create the BEST practical reference resource for players.

---

# Overall Brand Direction

## Core Design Philosophy

Vintage Story is:

- slower paced
- realistic
- atmospheric
- survival heavy
- historically inspired
- handcrafted
- earthy
- immersive

The website should visually communicate:

- cold winters
- forests
- clay
- blacksmithing
- agriculture
- ancient survival
- exploration
- progression
- craftsmanship

Avoid:

- futuristic UI
- neon colors
- esports styling
- overly modern/glassmorphism styles
- corporate design

This should feel like:

"an old survival handbook written by experienced survivors"
